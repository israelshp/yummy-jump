# קפיצה טעימה (Yummy Jump)

A joyful platform game for young kids, starring Shachar.
Collect the yummy food (🥑 avocado, 🍫 chocolate, 🍝 pasta, 🍌 bananas), jump over the yucky food (🧅 onion, 🥦 broccoli, 🍣 sushi), and hug Mom to fill your hearts back up.

## How to play
- **Computer:** arrow keys to move, Space or ↑ to jump.
- **Phone / tablet:** big on-screen buttons.
- Reach the pink flag to finish the level. Each level is a bit longer.

## Run it
It's a single self-contained `index.html`, so just open it in a browser.
To publish it online, enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main`, root).
